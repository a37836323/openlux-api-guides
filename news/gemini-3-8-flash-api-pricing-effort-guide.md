# Gemini 3.8 Flash 已上线：API 定价、调低 effort 与 Cyber 访问边界

**结论先说：**Gemini 3.8 Flash 已由 Google DeepMind 于 **2026 年 9 月 2 日**发布，并可在 **Gemini API、Google AI Studio 和 Android Studio** 中开始构建。介绍期价格为每百万输入 token **0.75 美元**、每百万输出 token **3.75 美元**，该价格到 **2026 年 12 月 31 日**结束；从 2027 年 1 月 1 日起，价格上调为 **1.50/7.50 美元**。

如果你的应用是长链路 Agent、软件工程或多步骤分析，可以优先验证 3.8 Flash；如果主要约束是计算成本，应测试较低的 `effort`，或者继续评估仍受支持的 Gemini 3.7 Flash。至于 Gemini 3.8 Flash Cyber，它不是普通开发者可直接调用的公开版本，而是通过 **Fairwind Program** 面向特定受信任防御方提供优先访问。

本文适合正在选择 Gemini API 模型、核算 token 预算、调节推理开销，或判断是否具备 Cyber 版本申请条件的开发者、企业技术负责人和安全团队。

## 一、API 是否可用：可以接入，但不要自行猜模型标识

### 官方发布事实

官方页面明确表示，Gemini 3.8 Flash 可在以下产品中开始构建：

- Gemini API；
- Google AI Studio；
- Android Studio。

因此，它具备面向 API 开发的公开入口。实际接入时，仍应登录自己的 Gemini API 或 Google AI Studio 环境，确认账户、项目和当前模型列表中是否出现该模型，并阅读对应开发者文档。

这里需要注意：已核验材料没有提供具体的模型 ID、接口路径、SDK 版本或请求示例。因此，不能仅凭“Gemini 3.8 Flash”这一产品名称拼接代码，也不能直接假设某个 `model` 字符串一定有效。

### 作者建议

先把“官方宣布可用”和“你的项目当前可调用”分开验证：

1. 在 Gemini API 或 Google AI Studio 中检查模型是否可见；
2. 打开官方开发者文档，确认模型标识、区域或账户限制、SDK 要求；
3. 用一个低风险、短输入的测试请求验证返回结果；
4. 再接入工具调用、长上下文或 Agent 循环。

如果控制台没有显示该模型，不应直接推断为模型已下线，也不要使用第三方目录结果代替官方账户内的可用性验证。

## 二、token 定价：先按日期分开做预算

### 官方价格

| 使用时间 | 每百万输入 token | 每百万输出 token | 预算含义 |
|---|---:|---:|---|
| 2026 年 9 月 2 日至 2026 年 12 月 31 日 | 0.75 美元 | 3.75 美元 | 介绍期价格 |
| 2027 年 1 月 1 日起 | 1.50 美元 | 7.50 美元 | 输入、输出单价均提高 |

按公开单价做基础估算时，可以使用：

> 预估费用 = 输入 token 数 ÷ 1,000,000 × 输入单价 + 输出 token 数 ÷ 1,000,000 × 输出单价

例如，某个假设工作负载每月使用 10M 输入 token 和 2M 输出 token，在介绍期按公开单价计算，基础估算为：

- 输入：10 × 0.75 = 7.50 美元；
- 输出：2 × 3.75 = 7.50 美元；
- 合计：15 美元。

若同样的用量发生在 2027 年 1 月 1 日之后，基础估算则为 30 美元。这个例子只用于说明单价变化，不代表任何实际用户用量，也没有纳入材料未说明的其他计费规则。

### 作者建议

不要只按平均请求量预算。3.8 Flash 面向复杂任务时可能执行更多推理步骤，并反复调用工具，因此输出 token 和整体链路用量可能上升。预算至少应分别建立：

- 普通问答或短任务；
- 多步骤代码任务；
- 带工具调用的 Agent 任务；
- 长时间运行或重复迭代的任务。

同时，为 2027 年价格切换预留独立预算。若产品生命周期会跨越 2026 年底，最好在财务模型中同时展示两套单价，而不是把介绍期价格当成长期价格。

## 三、如何理解并调低 effort：降低的是推理开销，不是简单“限字数”

### 官方发布事实

官方说明，3.8 Flash 在复杂任务和较高 `effort` 下，可能执行更多推理步骤，并以迭代方式调用工具。这样做可能提升复杂任务的处理表现，但也可能使用更多 token。

对于计算效率优先的应用，官方建议使用较低的 `effort`，或者继续使用仍受支持的 Gemini 3.7 Flash。

材料没有给出 `effort` 的具体参数名、可选值、默认值或 SDK 写法。因此，不能直接假定存在某个固定配置，例如 `effort="low"`，也不能把它等同于输出长度参数。

### 作者建议：用对照实验决定设置

对同一任务准备固定测试集，至少比较以下维度：

| 测试维度 | 需要记录的内容 |
|---|---|
| 结果质量 | 是否完成任务、代码或分析是否满足验收标准 |
| 推理成本 | 实际输入和输出 token 用量 |
| 工具行为 | 工具调用次数、是否重复调用、是否出现无效循环 |
| 稳定性 | 多次运行结果是否出现明显波动 |
| 业务成本 | 单任务成本及每个工作流的月度估算 |

测试时只改变 `effort`，尽量固定提示词、输入数据、工具集合和验收标准。然后按照官方开发者文档支持的方式设置参数。若文档没有明确说明某个参数可用于当前模型，就不要在生产环境中自行添加。

一个实用的决策规则是：

- **简单分类、抽取、短文本生成：**先验证较低 effort 是否足够；
- **代码修改、复杂分析、需要多次工具调用的任务：**保留较高 effort 的测试组；
- **成本敏感且任务容错较高：**优先考察低 effort；
- **任务经常需要长链路自主执行：**同时比较 3.8 Flash 与仍受支持的 3.7 Flash，而不是只看单次响应价格。

## 四、Gemini 3.8 Flash Cyber：访问边界比普通 Flash 更严格

### 官方发布事实

Gemini 3.8 Flash Cyber 通过 Fairwind Program 向以下受信任防御方提供优先访问：

- 政府机构；
- 关键基础设施运营商；
- 软件维护者。

官方还说明，该版本采用了更宽松的网络安全缓解措施，因此不面向通用开发者开放。普通 Gemini 3.8 Flash 与 Cyber 版本不能简单视为同一个公开 API 产品，也不能因为普通 Flash 可在 Gemini API 中使用，就推断 Cyber 版本会出现在同一模型列表中。

材料没有提供 Cyber 版本的公开价格、通用 API 入口、申请通过条件或审批时限。因而不能用普通 3.8 Flash 的 0.75/3.75 美元价格替代 Cyber 价格，也不能承诺申请后一定获得访问。

### 作者建议

只有在组织确实承担防御性网络安全工作，并属于上述机构或角色范围时，才值得进一步准备申请材料。准备时应清楚说明：

- 组织身份及软件、基础设施或政府职能；
- 使用场景是漏洞发现、修复或其他防御任务；
- 数据处理、权限控制和审计安排；
- 谁负责模型输出复核以及漏洞修复上线。

若只是普通应用开发、代码补全或安全学习，不应把 Cyber 版本作为当前可用依赖。可以先评估普通 3.8 Flash 的合规使用边界，并根据任务需求选择合适的安全控制。

## 五、从 3.7 Flash 迁移到 3.8 Flash 的验证步骤

如果现有系统使用 Gemini 3.7 Flash，不建议直接替换后上线。可以按以下顺序迁移：

1. **建立基线：**保存当前 3.7 Flash 在代表性任务上的质量、token 用量和工具调用记录。
2. **确认接入：**在 Gemini API 或 Google AI Studio 中验证 3.8 Flash 的实际可用性，并从官方文档取得准确模型标识和参数格式。
3. **小规模对照：**用相同输入和工具配置运行 3.7 Flash、3.8 Flash，以及不同 effort 设置。
4. **检查长链路行为：**重点观察是否出现更多推理步骤、重复工具调用或输出 token 增长。
5. **重新核算账单：**分别按 2026 年 12 月 31 日前和 2027 年 1 月 1 日后的价格计算。
6. **分阶段放量：**先将模型用于可回滚的内部任务，再扩展到有明确验收标准的生产流程。
7. **保留回退方案：**对于计算效率优先的路径，保留 3.7 Flash 或较低 effort 配置作为对照和回退选项。

- [ ] 已完成最小请求验证；
- [ ] 没有把产品名称直接当作接口参数。

### 成本与 effort

- [ ] 输入、输出 token 分开统计；
- [ ] 已分别计算 2026 年介绍期和 2027 年价格；
- [ ] 已测试较低 effort 对质量和工具调用的影响；
- [ ] 已评估长链路任务的额外 token 消耗；
- [ ] 已为价格变更准备预算更新流程。

### Cyber 访问

- [ ] 组织属于官方列出的受信任防御方范围；

- [ ] 没有把普通 Flash 价格或 API 入口套用到 Cyber；
- [ ] 未获得 Fairwind Program 访问前，不将 Cyber 作为生产依赖。
